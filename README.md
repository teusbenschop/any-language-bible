# any-language-bible
Any Language Bible

## Functionality sheet

### After installation
* Opens Read tab.
* Displays Bible installation steps.
* Search tab, type search word, it says: No search index etc.
* Bookmarks tab: No bookmarks yet
 
### Settings tab
* Button: Download list of modules
* Gives progress on download
* Gives number of modules after download.
* Button changes to: Update list of modules.
* Displays box to filter modules.
* If no matches, displays: No matches.
* Box has clear button.
* If matches, displays the matching Bibles.
* Tap a Bible to download and open it in the Read tab.
* Displays download progress.

### Read tab
* Header displays book and chapter.
** Click to select chapter.
** Back button to select book.
* Displays one verse per line.
* Tap verse to select it.
** Opens selection bar.
*** Color marker.
*** Copy verse to clipboard.
*** Share verse to app.
*** Bookmark verse.
*** Close bar.
* Tap another verse to add range selection.
* Remembers scroll position per chapter.

### Search tab
* Type word or phrase.
* Button to empty search box.
* List search results by relevance.
* Tap search result:
** Switches to Read tab
** Briefly highlights the verse.

### Bookmarks tab
* Lists bookmarks plus date
* Slide bookmark to the left to delete it.
* Tap bookmark:
** Open Read tab.
** Briefly highlights the verse.
